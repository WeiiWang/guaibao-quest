## 一、繪圖板（著色本）

試過：著色頁列表 → 開頁 → 填色（純色 + 彩虹 / 亮片 / 條紋 / 點點）→ 筆刷（細 / 中 / 粗）→ 橡皮擦（掃過筆刷、點填色區）→ 貼紙（加入、拖曳、縮放手柄）→ 復原 → 全部清除（有確認）→ 完成 → 掛到房間 → 畫廊；三種尺寸。

**P1　筆刷只有一種「圓頭麥克筆」，粗筆像一坨色塊，線條是折線不平滑**　〔嚴重度：高｜3、4、7 歲都受影響，7 歲最明顯〕
- 位置：著色頁 → 筆刷。`45-brush-strokes-land.png`（細 / 中 / 粗三種各畫一圈）、`41-paint-open-land.png`（只有「細 中 粗」三個選項）。
- 問題：這就是已知回饋「著色要有筆刷」的現況：只有顏色 + 3 種粗細（5 / 12 / 26），沒有任何筆觸差異；`PaintBoard.tsx` 的 `drawStroke` 是 `lineTo` 折線，手快一點就有稜角（45 的細線圓圈能看出多邊形）；粗筆 26 單位在畫板上約 45px，一筆就蓋掉線稿。
- 建議：
  - 筆刷改成「類型」而不只是粗細：蠟筆（帶紋理）、水彩（半透明可疊色）、彩虹筆（顏色沿路徑漸變）、亮片筆、點點筆、印章（連點蓋一個小星星 / 愛心，3 歲最愛）。`ColoringStroke` 加 optional `brush` 欄位（規格說不升 Dexie 版本，optional 欄位可行）。
  - 路徑改用 quadratic 平滑（取相鄰點中點當控制點）。
  - 工具列用圖示按鈕 + 筆觸預覽，不要只有「細 中 粗」文字。
  - 粗筆上限降到約 18，避免一筆蓋掉線稿。

**P2　圖案太簡單，且 18 張全是「單一圖示」、只有 10–14 個區塊**　〔高｜4、7 歲最明顯，3 歲其實剛好〕
- 位置：`143-shop-coloring-all.png`（商店著色頁分頁全覽）、`41-paint-open-land.png`（免費的小猴子：只有頭、臉、肚子、手腳等 14 塊，而且長得像大猩猩）、`40-col-list-land.png`。
- 問題：已知回饋「圖案太簡單」屬實：每張都是一個小圖示（小魚、花朵、小汽車…）加邊框，沒有場景、沒有細節層次；7 歲填完 14 個色塊不到 2 分鐘。新孩子只送 2 張（小猴子、香蕉樹），其餘 16 張 30–40 星；而在著色本列表裡，上鎖頁只顯示鎖頭（`40-col-list-land.png`），看不到買了會得到什麼（商店裡才有縮圖）。
- 建議：
  - 新增三類頁：① 場景頁（花果山、水簾洞，40+ 區塊，可從現有地圖美術抽線稿）；② 數字 / 點點連線頁（7 歲挑戰）；③ 「空白畫布」模式（只有筆刷與貼紙，3 歲最愛亂畫）。
  - 著色頁加難度標示（1–3 顆星）與區塊數。
  - 著色本列表的上鎖頁改成「灰階剪影 + 價格」，不要只有鎖頭。
  - 畫完的完成度（現在不影響任何事）可以綁小獎勵（見 G1）。

**P3　筆刷沒有多點觸控 / 手掌防護，第二根手指會畫出直線**　〔高（3、4 歲）｜程式讀出來 + 模擬驗證〕
- 位置：`46-brush-touch-2finger-land.png`（單指畫線中，第二個觸點按下後，畫面出現一條橫跨的直線；復原步數只多 1，表示兩個觸點被併進同一筆）。
- 問題：`PaintBoard.tsx` 的 `onCanvasDown` 沒有檢查 `e.isPrimary` 或 pointerId，`live.current` 只有一個；3、4 歲孩子畫圖時整隻手掌靠在 iPad 上很常見，會產生巨大的誤筆跡。這是推論加模擬，真機要再驗。
- 建議：筆畫開始時記下 `pointerId`，其他 pointerId 一律忽略；`touch` 的接觸半徑（`e.width/e.height`）過大（>40px）視為手掌，不畫；兩指同時按下時取消目前這筆。

**P4　橡皮擦是「整條線刪除」，說明是一整段文字**　〔中｜3、4 歲〕
- 位置：`48-eraser-land.png`。
- 問題：筆刷線被擦到就整條消失，不是擦掉經過的部分，跟孩子對橡皮擦的認知不一致（擦一點、整條不見）；說明文字「點填色的地方清掉顏色，或在筆刷線上滑過去擦掉」是長句，不識字的孩子看不懂，也沒語音。
- 建議：改成 canvas `destination-out` 的局部擦（stroke 資料改存成 bitmap 層或把線切段）；說明改成圖示（手指點色塊 → 顏色消失）+ 一句語音；擦完有「噗」的粒子。

**P5　貼紙：風格不搭、疊在同一個位置、手柄太小**　〔中｜3、4 歲〕
- 位置：`50-sticker-added-land.png`、`51-sticker-moved-land.png`、`sheet-paint-phone.png`。
- 問題：
  - 18 張貼紙是 3D 渲染圖，貼在黑線稿上風格差很多（`51`）。
  - 每次新增的貼紙都固定出現在畫板中央，第二張直接蓋在第一張上，孩子會以為沒加成功。
  - 縮放 / 旋轉只靠右下角一個 34×34 的手柄（<56px），沒有雙指縮放；`＋ － ⟲ ⟳` 是 56×48 的符號鈕。
  - 手機貼紙列只露出 6 / 18 張，要橫滑。
- 建議：新貼紙隨機偏移並自動避開既有貼紙；手柄放大到 ≥56px 或改成選取後出現大的「變大 / 變小」圖示鈕；加雙指縮放旋轉；貼紙可以從托盤「拖進畫布」，並提供「印章模式」（選一張，之後每點一下就蓋一個）。

**P6　調色盤面板會「跳」：第一次用色後多出一整列「最近用過」**　〔中｜3 歲、4 歲〕
- 位置：`41-paint-open-land.png` → `42-filled-land.png`（色票整組往下掉約 60px，同一個位置原本是別的顏色）。
- 問題：孩子在同一點連點想換色，位置在中途改變；橡皮擦頁籤的長說明也讓下方整組位移。
- 建議：「最近用過」列預留固定高度（空的時候放 6 個空圈），各工具的選項區固定高度。

**P7　完成之後沒有任何獎勵、半成品也能「完成」，掛畫位置會蓋住窗戶**　〔中｜4、7 歲〕
- 位置：`55b-finish-2.3s.png`（43% 就能完成並慶祝）、`56-hung.png`、`110-home-port.png`（直向首頁，畫掛在窗戶上）。
- 問題：完成慶祝是整個遊戲裡很少有的「作品被稱讚」時刻，但沒有任何收藏回饋（星、貼紙、畫框）；掛到房間的預設位置不管空位，在 iPad 直向會蓋在窗戶上；掛成功只有一行「到首頁佈置可以移動它」的小字 toast。
- 建議：完成度達 70% 以上才顯示「完成」慶祝，否則問「再畫一點好嗎？」；完成給一張新貼紙或畫框（非星星，避免經濟膨脹）；掛畫自動挑空牆面。

**P8　直向 / 手機的顏色只有一排、需橫滑，24 色看不到一半**　〔低｜3、4 歲〕
- 位置：`sheet-paint-port.png`、`sheet-paint-phone.png`。
- 說明：直向工具列在畫布下方固定、不需上下捲動（上輪 #6 已改善），但色票是單排橫滑，手機一次只露 6 色。可接受；建議至少顯示「最近用過」固定不動，剩下的橫滑。

**這區塊沒問題的部分**：填色邏輯、特殊填色四種、復原（有步數）、全部清除有確認且可復原、自動儲存、畫廊 / 掛到房間可用、色票 ≥48px、工具按鈕 81×68。

## 二、遊戲性與玩法（重複感、目標感、驚喜）

**G1　每題的即時獎勵太淡，站末畫面也看不到食物**　〔高｜3、4 歲〕

## 六、最值得做的 10 件事（依「對孩子的留存 / 回饋」× 實作成本排序）

1. **每題答對的即時獎勵 + 站末結算先掉食物**（G1、V3、B4）
   - 為什麼：這是已知孩子最愛的環節，現況最弱。實作主要在 StageScreen 與 Ceremony，不動題庫。
   - 取捨：不要用機率獎勵（規格「不做成癮」）；粒子與聲音要遵守 `prefers-reduced-motion` 與音效開關。

2. **選題多樣性規則：同站同題型 ≤2、近 8 題不重複物件、英文難度 1 混入 pic2en / zh2en**（G2）
   - 為什麼：重複感是已知回饋，而且是 `select.ts` 的結構問題，改一次受益三個孩子、四個科目。
   - 取捨：題庫量不夠時會退回重複；英文與自然的難度 1 題型要補生成器與題數（同一份「唯一解、答案位置均勻」檢查）。

3. **筆刷升級：蠟筆 / 水彩 / 彩虹 / 印章 + 路徑平滑 + 手掌 / 多指防護**（P1、P3、B3）
   - 為什麼：已知回饋、3 歲最常用的玩法，也是孩子最久的停留時間。
   - 取捨：stroke 結構要加 optional 欄位，渲染與匯出（`export.ts`）都要處理；水彩半透明在 canvas 重畫時要小心效能。

4. **新增場景著色頁 + 空白畫布 + 上鎖頁剪影預覽**（P2）
   - 為什麼：「圖案太簡單」、7 歲 2 分鐘填完。
   - 取捨：美術成本最高，可先用現有地圖美術抽線稿、再用 AI 生成；區塊多的頁要考慮點擊精度與效能（SVG 區塊上限）。

5. **3 歲的首次體驗三件套：onboarding 問年齡、數字題二次點擊提示、新手送星星與食物**（O3、G6、G9）
   - 為什麼：都是「3 歲孩子第一次玩就卡住」的點，改動小（一頁 onboarding、一個提示動畫、一次 seed）。
   - 取捨：送星星會稍微稀釋「星星來自任務」的意義，建議一次性、數量小。

6. **禮物改成角落禮物袋、一次全收、不在餵食中途彈出**（O1）
   - 為什麼：目前會擋住孩子最愛的「餵食看反應」。
   - 取捨：少了「阿悟拿出禮物」的小戲劇，可以保留一次性的動畫，而不是每個都演。

7. **圖鑑納入全科物件並加熟悉度等級**（G4、B1）
   - 為什麼：7 歲目前沒有長期收集目標，圖鑑是最便宜的重玩理由。
   - 取捨：需要為英文 / 生活 / 自然的圖補 `FRIENDS` 資料與縮圖；熟悉度等級要新增 optional 欄位。

8. **6–7 歲快速分級與挑戰站**（G3）
   - 為什麼：避免 7 歲孩子在第 1 章被無聊勸退。
   - 取捨：分級過高會挫折，所以一定要有「降一級」的自動機制，且不能讓家長以為孩子「跳級」就是會了。

9. **孵化 / 成長可視化（蛋的 4 個外觀）與里程碑小獎**（G5）
   - 為什麼：一個月才成體太久，孩子要看到「有在進步」。
   - 取捨：美術要多生 3 張蛋圖；若同時調高食物掉落量，要確認不衝擊商店的星星經濟。

10. **佈置動線與多樣性：「去工坊」導向、新增可重複擺放的小物與換色、直向地圖不裁切**（O2、V7，加上目前家具每件只有 1 個、壁紙 6 款、地板 4 款）
    - 為什麼：已知回饋「佈置要更多樣」；導向錯誤是明確 bug，順手修。
    - 取捨：「可重複擺放」會改變家具擁有數的資料結構（inventory qty 已有，可沿用）；新增美術量大，可先做換色變體（CSS filter）當低成本方案。
