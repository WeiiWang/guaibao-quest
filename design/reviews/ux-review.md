# 乖寶任務 UX 審查（4–7 歲、不識字使用者視角）

審查日期：2026-10-27　　範圍：只審查、未改任何程式碼
方法：Playwright（Chromium + hasTouch，拖曳用 CDP 真實觸控事件），尺寸 1024×768、768×1024、375×812（手機另開 isMobile）。小孩流程走完：onboarding → 首頁 → 冒險一整章（含答錯 1 次、2 次、章末寶箱）→ 工坊做家具/壁紙 → 佈置拖拉 → 商店買食物 → 餵食（點、拖）→ 便便清理 → 日夜睡覺 → 著色（填色/彩虹/筆刷/貼紙/完成/掛房間/畫廊）→ 今日任務申請 → 家長審核與各分頁 → 時間到鎖定畫面。
截圖都在 `design/reviews/ux-shots/`（下面只寫檔名）。

## 沒測到、要靠真機補的

- 語音與音效：headless 聽不到。只能從程式確認「語音只用在冒險關卡、章末、鎖定畫面」，沒有親耳驗證音質與 iPad 靜音鍵影響。
- 觸控行為用 Chromium 模擬，iPad Safari 的捲動手勢判定可能略有差異（見 #5，建議真機確認）。
- 阿悟的暈眩、搔癢、捏鼻子等行為動畫只抓到靜態畫格，沒逐項檢查。
- 「重設全部資料」按鈕有沒有二次確認沒測。

## 一、問題清單

嚴重度：高＝小孩會卡住或誤觸造成損失／中＝困惑或費力／低＝美觀

### 高

**#1　鎖定畫面的兩顆按鈕被縮成小圓、文字斷行（版面 bug）**
- 嚴重度：高　畫面：遊玩時間到的鎖定畫面　尺寸：1024×768（其他尺寸用同一份 CSS，未逐一截）
- 截圖：`71-lock-screen-1024x768.png`、`73-lock-back-home-1024x768.png`
- 問題：「今日任務」「著色本」是小孩在鎖定時唯一能按的出口，卻變成約 58px 的圓形，「今日任務」被斷成「今日任／務」。原因是 class 名稱 `.lock-btn` 同時被首頁右上角的家長鎖頭圓鈕（`src/ui/styles.css:277`）和鎖定畫面按鈕（`src/ui/components/lock.css:19`）使用，圓形規則蓋掉了膠囊樣式。
- 建議：鎖定畫面按鈕改用獨立 class（例如 `.lock-go`），做成 ≥ 72px 高的大膠囊，前面放任務/畫筆圖示。

**#2　著色本一開始全部上鎖，小孩進去是死路**
- 嚴重度：高　畫面：首頁 → 著色本（首頁四大按鈕之一）　尺寸：三種
- 截圖：`47-coloring-list-1024x768.png`、`47b-coloring-tap-locked-1024x768.png`（點鎖頭完全沒反應）、`47c-coloring-list-bought-1024x768.png`
- 問題：新使用者 18 張全是鎖頭，唯一說明是一行小字「還沒有著色頁，到商店用點數買一張吧！」。不識字的小孩看到只有鎖頭，點了沒有聲音、沒有動畫、沒有導向商店；而且新手 0 星星也買不起（最便宜 30 星）。擁有的頁和上鎖的頁照固定順序混排（已買的不會排前面），買了後面的頁就會被鎖頭夾在中間。
- 建議：(a) 首次給 1–2 張免費頁；(b) 點鎖頭時阿悟搖頭 +「去商店買」語音 + 閃一下首頁商店圖示，或直接帶去商店著色頁分頁；(c) 已擁有的排最前面，上鎖的收成一排縮小「更多」。

**#3　餵食「點一下就餵」，沒有任何防呆，吃飽了仍會扣食物，連點會燒光**
- 嚴重度：高　畫面：首頁食物欄　尺寸：三種
- 截圖：`34-after-eat-1024x768.png`（飽足條已滿）、`67-food-spam-1024x768.png`
- 問題：食物欄的每個圖示被輕點（不拖）就直接餵（RoomView `finishPress`：`!p.started` → `feed`）。飽足已 100% 也照扣；實測飽足已滿時 0.6 秒內連點 6 下消耗了 2 個食物（吃的動畫進行中擋掉其餘）。4–7 歲小孩點圖示的習慣動作就是狂點。食物是用星星買的（蛋糕 60 星），誤觸等於損失，且吃多了還會多長便便。另外 `feedCount` 也被誤增，影響進化進度。
- 建議：飽足 ≥ 100（或某個上限）時不扣食物，阿悟搖頭說「肚子好飽喔」＋食物彈回；或改成「只能拖給阿悟」，輕點只出現小抖動提示「拖給我吃」。

**#4　商店「買」立即扣星星，沒有確認，雙擊會買兩次**
- 嚴重度：高　畫面：商店（飼料／著色頁）　尺寸：三種
- 截圖：`35-shop-1024x768.png`、`36-shop-bought-1024x768.png`
- 問題：實測間隔 80ms 連點兩下「香蕉」：星星 160→140，買了 2 個（每個 10）。蛋糕 60 星、著色頁 30–40 星，雙擊的損失更大。按鈕只有文字「買」，沒有圖示和語音，也沒有「確認買？」的步驟。
- 建議：買之前加一次大圖確認（物品大圖 + 星星數 + 勾/叉兩顆大圖示按鈕），或按鈕在按下後 600ms 內鎖住；買成功用星星飛出 + 音效，不要只靠 toast 文字。

**#5　從左邊的食物往「右上」拖，常會變成捲動食物欄而不是拖食物（拖曳失敗且沒回饋）**
- 嚴重度：高　畫面：首頁食物欄 → 阿悟　尺寸：1024×768（手機/直向理論上更常發生）
- 截圖：`29-feed-drag-over-pet-1024x768.png`（拖曳中整個畫面被推動）、`32-feed-miss-fly-back-1024x768.png`
- 問題：`.dock-item` 設 `touch-action: pan-x`（`styles.css:587`），所以起手方向偏水平時，瀏覽器會把它當成捲動、取消拖曳。實測：從最左邊的胡蘿蔔（x=128）直線拖向阿悟（位移 +384, −216，偏水平）→ 沒餵到（feedCount 沒變）；從中間項（x=422，位移 +90, −216，偏垂直）或先垂直拖再轉彎 → 成功。小孩的手指軌跡不會先垂直再轉彎，第一個到第三個食物最容易失敗，且失敗時沒有任何提示。
- 建議：食物圖示改 `touch-action: none` 並用「長按 150ms 才拖、否則捲動」，或食物欄不用橫捲（兩排網格 / 翻頁箭頭），或直接加強「點一下」模式（見 #3 防呆後保留）。真機務必驗證。

### 中

**#6　直向與手機的著色頁：調色盤在畫面外，換色必須捲動**
- 嚴重度：中　畫面：著色頁　尺寸：768×1024、375×812（1024×768 沒問題）
- 截圖：`h-paint-768x1024.png`、`h-paint-375x812.png`、`h-paint-sticker-768x1024.png`
- 問題：畫布佔滿寬度，工具列掉到下面；進頁面只看得到「填色/筆刷/貼紙/橡皮擦」，顏色要往下捲，每換一次色都要捲一次，「完成」在第三屏。直向總高約 1417px、手機約 2000px。
- 建議：直向把工具列固定在底部（colour dock），畫布限制在可視高度內；顏色用一條可橫滑的色條。

**#7　色票 37px，24 色擠在一起、相近粉彩難分，且工具列高度一變按鈕就跳位**
- 嚴重度：中　畫面：著色頁　尺寸：1024×768（最小觸控目標）
- 截圖：`48-paint-start-1024x768.png`、`52-fill-rainbow-1024x768.png`、`56-sticker-added-1024x768.png`
- 問題：色票 37×37（最近用過 40）、間距約 7px，不到 44px 標準，更別說小孩該有的 56px+；前 8 色是接近的粉彩（粉橘、淡黃、淡綠、淡青）。工具列高度會變：純色時「完成」在 y=412，點第一個顏色出現「最近用過」後變 y=462，切到貼紙變 y=568。小孩剛點完色，「全部清除／完成」就移位，容易按錯（清除有確認，完成沒有）。
- 建議：色票 ≥ 56px、預設只顯示 12 個鮮明色（粉彩色收進「更多」）；工具列固定高度，主按鈕（復原/完成）固定位置。

**#8　離開關卡沒有確認，進度整站重來**
- 嚴重度：中　畫面：關卡左上「← 離開」　尺寸：三種
- 截圖：`75-reenter-station-1024x768.png`（重進後回到第 1 題）；手機直向上它是只有「←」的圓鈕，`h-q1-kind-375x812.png`
- 問題：答到第 3 題按離開，沒有任何詢問、也沒有存檔，重進同一站從第 1 題開始。按鈕 96×56 在左上角，不算近，但小孩把它當「上一題」按到的機率高；手機版只剩一個「←」。
- 建議：離開前跳出阿悟「要先休息嗎？」+ 勾/叉大按鈕，或存當前題號讓小孩繼續。

**#9　掛到房間的畫被左上角狀態卡蓋住**
- 嚴重度：中　畫面：首頁　尺寸：三種
- 截圖：`62-home-with-artwork-1024x768.png`、`h-home-768x1024.png`、`h-home-375x812.png`
- 問題：「掛到房間」的作品預設放在牆面左上，剛好被「阿悟 好開心／飽足」資訊卡壓住，小孩最得意的畫看不到，也不知道在哪。（夜間也同樣：`68-night-sleeping-1024x768.png`）
- 建議：預設位置避開 HUD（放牆面中央偏右、窗戶旁），掛上後讓畫框閃一下並自動捲到那裡；牆面上方 ~200px 視為 HUD 保留區。

**#10　工坊：全部按鈕都是灰的「還差 X」，不識字無法判斷哪些做得起；做好沒有慶祝**
- 嚴重度：中　畫面：工坊（家具/壁紙/地板）　尺寸：三種
- 截圖：`24-workshop-3wood-1024x768.png`（剛開始）、`39-workshop-after-craft-1024x768.png`、`42-workshop-wall-applied-1024x768.png`
- 問題：只有 3 個木材時 24 件家具全是灰色「還差 石頭1 花朵3」的文字，沒有一個看起來「可以做」。按「製作」後只有底部 toast 一行字（會蓋住下一排按鈕），卡片只是淡淡變色、按鈕變「去佈置」。24 件家具需要捲兩屏（直向 2224px、手機 3566px）。「套用」「使用中」也是文字。材料成本用圖示是好的。
- 建議：做得起的卡片放最前面、發光、按鈕用扳手圖示；做不起的把缺的那個材料圖示放大紅框＋「差 2」；做好時卡片放大彈跳＋音效＋家具飛向背包；壁紙直接「點卡片就套用」。

**#11　商店、工坊、任務完成都沒有聲音與語音，成功全靠 toast 文字**
- 嚴重度：中　畫面：任務/商店/工坊/著色完成　尺寸：三種
- 截圖：`11b-task-3-submitted-1024x768.png`、`36-shop-bought-1024x768.png`、`39-workshop-after-craft-1024x768.png`
- 問題：全專案 `speak()` 只出現在關卡、章末、鎖定畫面（程式碼確認）。「好棒！等爸媽確認囉」「買到香蕉了！」「做好了時鐘」都是 2.8 秒就消失的字。首頁的主選單按鈕、食物名稱、任務標題也都不會唸。不識字的小孩得靠家長讀。
- 建議：建立一組統一回饋（短音效 + 一句語音 + 動畫），並在任務標題旁加小喇叭或按一下就唸。優先順序見第三節。

**#12　擺設模式：家具只有 59–68px、操作文字化**
- 嚴重度：中　畫面：首頁 → 佈置　尺寸：1024×768
- 截圖：`43-edit-mode-1024x768.png`、`44-edit-placed-0-1024x768.png`、`44-edit-placed-2-1024x768.png`
- 問題：剛放好的時鐘 59×59、球 68×69，拖回去調整需要精準觸碰。選中後的工具列「↔ 翻轉／⬆ 最前／✕ 收回」都是文字；提示「佈置中：把裝飾拖進房間，拖回下方可收回」是小字。「收回」緊靠「最前」，雖然不傷資料，但小孩會以為家具被刪掉。
- 建議：家具預設尺寸放大 1.3 倍、選中時顯示 ≥ 64px 的角落把手；工具列改圖示（翻轉箭頭、層疊、背包圖示）並補語音；提示用動畫手指示範一次。

**#13　地圖上點已完成／未解鎖的站，完全沒反應；直向/手機要橫滑才看得全**
- 嚴重度：中　畫面：冒險地圖　尺寸：三種
- 截圖：`04-map-1024x768.png`、`h-map-768x1024.png`、`h-map-375x812.png`
- 問題：鎖頭站與已通關站都是 `disabled`（`MapScreen.tsx:126`），點了沒有聲音、抖動、語音。已通關的站不能重玩（要到寶箱後的「再玩一次」）。直向/手機只看得到 3 站，需橫滑，提示「左右滑動看整張地圖 ↔」是小字，手機上站 1 的名字被切掉（「小路」）。1024×768 的設計是最好的。
- 建議：點鎖頭時阿悟搖頭＋「還沒到喔」；已通關站可以點擊重玩；直向時把地圖自動置中在目前站，並加閃動的箭頭。

**#14　答錯回饋偏弱、提示文字太長**
- 嚴重度：中　畫面：關卡答錯　尺寸：1024×768
- 截圖：`07-q2-wrong1-1024x768.png`、`07-q4-wrong1-1024x768.png`、`07-q4-wrong2-1024x768.png`
- 問題：答錯時選項只是變成淡粉色半透明，沒有 ✗、搖晃，阿悟在蛋階段也沒有「想一想」姿勢（蛋沒有 pose）。「跟阿悟一起，一個個慢慢數。數到最後一個，就是答案囉。」這類提示要靠語音；原題目被縮成小灰字。正向（答對）做得好：卡片轉綠、阿悟歡呼、1.6 秒自動下一題、數數時逐一亮號碼。
- 建議：答錯卡片左右抖 2 下再淡化；蛋階段在畫面角落另放一隻「想一想」的小猴/問號泡泡；提示改為「動畫為主、語音一句話」。

**#15　今日任務：「我做完了」沒有確認、不能撤回；標題沒語音**
- 嚴重度：中　畫面：今日任務　尺寸：三種
- 截圖：`10-tasks-1024x768.png`、`11b-task-3-submitted-1024x768.png`
- 問題：五顆一模一樣的藍色「我做完了」，點下去就變成「等爸媽確認」，沒有「真的做完了嗎？」，也不能收回。任務圖示（emoji）有幫助，標題與星星數是小字。
- 建議：按下後出現大圖「做完了嗎？✔／✖」；點任務圖示會唸「寫功課，完成可以得三顆星」。

**#16　家長區分頁列被切掉，「設定」「PM 預覽」看不到**
- 嚴重度：中（家長）　畫面：家長區頂端分頁　尺寸：三種
- 截圖：`14-parent-review-1024x768.png`、`h-parent-review-375x812.png`
- 問題：10 個分頁一排，1024 寬就把最後兩個擠到畫面外，只露一半文字，沒有箭頭或漸層提示可以橫滑；手機只看得到 3 個。家長會找不到「設定」（有「寵物會大便」開關、更改 PIN）。
- 建議：用兩排或下拉；常用的（審核、學習報告、遊玩時間）固定；其餘收進「更多」。

### 低

**#17　房間左右的「‹ ›」箭頭長得像返回鍵**：`02-home-1024x768.png`。小孩會點「‹」想回上一頁，其實是捲動房間。建議改成更像「看旁邊」的眼睛/房間圖示，或房間不用捲動就看得到全部。

**#18　食物欄超出可視範圍，且順序會因庫存變動**：`27-home-adult-fed-1024x768.png`、`68-night-sleeping-1024x768.png`。10 種食物只看得到 5.5 個，最右邊被切一半（靠半截提示可捲動）；吃完一個庫存 0 後它會跑到最右邊，肌肉記憶被打亂。建議庫存 0 的收到一個「去商店」圖示，其餘順序固定。

**#19　首次進首頁沒有任何引導**：`02-home-1024x768.png`、`ob-first-home-375x812.png`。0 星星、全是灰色「去商店買」的食物、蛋；沒有「先去冒險地圖」的手指動畫或語音。建議第一次進首頁讓冒險地圖按鈕跳動並唸「我們去冒險吧」。

**#20　toast 蓋住底部按鈕**：`37-shop-coloring-1024x768.png`、`39-workshop-after-craft-1024x768.png`。toast 固定在底部中央，剛好蓋住「買」「製作」按鈕、持續 2.8 秒，連續操作時會按到被擋住的按鈕。建議移到畫面上方，或讓 toast 不攔截點擊（pointer-events: none）。

**#21　返回鈕名稱與樣式不一致**：`04-map`、`05-stage-intro`、`61-gallery`。「回首頁」「離開」「回地圖」「著色本」，圖示有「‹」「←」，手機版關卡只剩 ←。著色頁 → 著色本 → 首頁需要兩步。建議全站統一一個「房子」圖示的首頁鈕，位置固定。

**#22　內容用詞偏抽象**：`07-q2-wrong1-1024x768.png`。「哪一個是大自然？」對 4–5 歲很抽象（葡萄不是大自然嗎？），建議改成「哪一個會游/會飛/長在樹上」之類具體說法。這是內容品質，不是版面。

**#23　其他美觀小項**
- 工坊首屏有星星特效殘留在標題旁（回首頁時補發的飛星動畫在別的畫面出現）：`24-workshop-3wood-1024x768.png`。

## 二、不識字友善度總評

**偏弱，約 6/10。** 視覺語言很強（3D 大圖、顏色分區、糖果按鈕），冒險關卡是全站唯一有「語音 + 動畫 + 音效」的區域，已達到不識字也能玩的程度。但離開關卡後，語音完全消失：首頁、任務、商店、工坊、著色全靠文字按鈕（「買」「製作」「套用」「我做完了」「還差 木材2」）與 toast 小字，不識字的小孩第一次用需要家長在旁邊讀。能靠圖示猜出的有：首頁主選單、食物、家具；猜不到的有：所有狀態文字（已擁有、使用中、還差、等爸媽確認）與所有錯誤/空狀態說明。

最該補語音或視覺引導的 5 個地方（依影響排序）：

1. **著色本空狀態/鎖頭點擊（#2）**：目前是死路，需語音「這張要去商店買喔」+ 動畫導向商店。
2. **所有「成功」時刻（買、做、申請任務）（#11）**：統一「音效 + 一句語音 + 星星/物品飛行動畫」，取代 toast 文字。
3. **餵食與首頁食物欄（#3、#5、#18）**：「肚子好飽」要用阿悟表情與語音；首次引導用手指動畫示範「拖給阿悟」，不要只有一行字。
4. **工坊的可做/不可做（#10）**：用發光/灰階表達狀態，缺料用放大的缺少材料圖示，點卡片唸出家具名稱與缺什麼。
5. **鎖定畫面與任務（#1、#15）**：鎖定畫面除了唸「我想睡覺了」，下方出口要是大圖示按鈕；任務卡點圖示唸標題，送出前用大圖確認。
